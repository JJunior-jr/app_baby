## 🚀 COMO COMEÇAR (3 Opções)

### Opção 1: Rápido (5 min)
```bash
cd app_baby
cp .env.docker .env
docker-compose up -d
docker-compose exec api python init_db.py
# http://localhost:8000/docs
```

### Opção 2: Verificado (10 min)
```bash
bash verify-docker-setup.sh
bash validate-env.sh dev
docker-compose up -d
docker-compose exec api python init_db.py
curl http://localhost:8000/api/health
```

### Opção 3: Produção (30 min)
```bash
cp .env.prod.example .env.prod
bash generate-secret.sh >> .env.prod
# Edit .env.prod com valores reais
bash validate-env.sh prod
docker-compose -f docker-compose.prod.yml --env-file .env.prod up -d
```
